# 🎪 Гермес: MAX Афиша & Пульс города 24/7

> **Флагманский массовый сервис и Mini-App для мессенджера MAX на всероссийский [Хакатон MAX (VK)](https://hackathon-max.vk.company/).**

## ▶️ Запуск для жюри

**Онлайн:** https://hermes-gorod.site/app — приложение на отдельном сервере. ⚠️ Домен сейчас заблокирован: без VPN он не открывается, **с VPN открывается**. Ждём разблокировки домена; до тех пор проверить проект можно локально (команды ниже).
Бот в MAX: @ideya_fiks_170_bot, внутри MAX кнопка в боте открывает Mini App.

**Локально, без токена и без настройки — одна команда** (нужен Python 3.10+ и интернет для первой установки):

```bash
python run_local.py
```

Скрипт сам создаст `.venv`, поставит `requirements.txt`, запустит сервер и откроет http://127.0.0.1:8020/app.
**Запуск по кнопке (двойной щелчок):** `RUN_LOCAL.bat` — без Docker, `RUN_DOCKER.bat` — в контейнере (нужен Docker Desktop). macOS/Linux: `bash run.sh` или `bash run.sh docker`. Порт: `python run_local.py --port 9000`, без браузера: `--no-browser`, проверка «поднимается ли»: `--check`.
Без `.env` работает демо-режим (бот-симулятор, афиша 56 городов, карта, «Вечер вместе», билеты с QR). Свой токен: `cp .env.example .env` и впишите `MAX_BOT_TOKEN`.

**Docker** (образ собирается из `Dockerfile`, порт 8000, данные в томе `/data`):

```bash
docker compose up -d --build
```
```bash
docker build -t hermes-gorod . && docker run -d --name hermes -p 8000:8000 -v hermes-data:/data hermes-gorod
```

После запуска: http://localhost:8000/app (проверка: http://localhost:8000/ready). Остановить: `docker compose down` или `docker rm -f hermes`.
Тесты: `docker compose --profile test run --rm tests` или `python -m pytest -q` в `.venv`.

**Что открыть за 2 минуты:** выбор города → перелёт между городами; «Прогулки» → «Вечер вместе» → «Показать, как это выглядит»; афиша → событие → билет с QR; карта → «Слои» → транспорт.
Проект по шагам: `ПОКАЗ_ЖЮРИ.md`; питч: `webapp/pitch_deck.html` (в приложении: `/deck`).

## 💡 Концепция: Федеральный продукт, нужный 100% пользователей MAX во всех городах России

Большинство хакатонных ботов фокусируются на узких нишах (ТСЖ одного двора, сдача налогов, запись к врачу), которыми пользуются редко или только определенные группы граждан в одном локальном месте.

**«Гермес»** — это массовый федеральный продукт ежедневного спроса (**daily-use product**), масштабированный на **все города России** (Москва, Санкт-Петербург, Казань, Сочи, Екатеринбург, Новосибирск, Нижний Новгород, Самара и др.):
- *«Куда сходить сегодня вечером в моем городе?»*
- *«Где выпить лучший спешелти-кофе рядом?»*
- *«Что посмотреть в кино на выходных со скидкой?»*
- *«Как найти бесплатную выставку рядом со мной и построить маршрут в Яндекс.Картах?»*
- *«Как быстро забронировать билет без перекупщиков прямо в чате MAX?»*

## 🌟 Ключевые возможности и функционал

### 1. 🏙️ Федеральное масштабирование на ВСЮ Россию (`/city`)
- **Мгновенный выбор любого города**: интерактивная клавиатура популярных мегаполисов (Москва, СПб, Казань, Сочи, Екатеринбург, Новосибирск, Нижний Новгород, Самара).
- **Ручной ввод любого города через FSM**: канонический парсинг и нормализация («мск» → «Москва», «питер» → «Санкт-Петербург»).
- **Автоматическое определение города по GPS**: отправка геопозиции через кнопку MAX `request_geo_location` мгновенно определяет город через Yandex Maps Geocoding API (с резервным геокодером Nominatim и офлайн-матчером Haversine).
- **Интеграция с KudaGo Open API**: подгрузка актуальных культурных событий и фестивалей по городам с умным кэшированием.

### 2. 🗺️ Интеграция с Яндекс.Картами (Маршруты & Навигация)
- Автоматическая генерация прямых ссылок на **Яндекс.Карты** (`mode=walking`, `mode=auto`).
- Построение оптимального пешеходного маршрута от текущей геолокации пользователя до выбранного заведения или события в 1 тап.

### 3. 🎯 Персонализированный 3-клик ИИ-Квиз (`/quiz`)
- Быстрый алгоритмический подбор досуга без длинных анкет:
  1. **С кем:** на свидании, с друзьями, с семьёй/детьми, в одиночку.
  2. **Вайб:** культура & искусство, гастрономия, драйв & спорт, чилл & кино.
  3. **Бюджет:** бесплатно (0 ₽), бюджетно (до 500 ₽), любой бюджет.
- Мгновенная выдача персонализированной подборки с фильтрацией по текущему городу пользователя.

### 4. 🎲 Рандомайзер «Мне повезёт!» (`/random`)
- Для тех, кто устал выбирать: спонтанный подбор одного яркого события или заведения в текущем городе с полной карточкой, промокодом и кнопкой бронирования.

### 5. ⭐ Персональное Избранное (`/favorites`)
- Сохранение понравившихся событий и мест в 1 клик (`afisha:fav_toggle:<id>`).
- Удобный список закладок с быстрой навигацией и актуальными статусами.

### 6. 🔍 Умный полнотекстовый поиск (`/search <запрос>`)
- Поиск по названию, описанию и категории с фильтрацией по городу и поддержкой русского языка (Unicode Cyrillic search).
- Моментальный поиск: `/search выставка`, `/search кофе`, `/search джаз`.

### 7. 🔗 Deep Linking (Глубокие ссылки MAX)
- Поддержка перехода по ссылкам из наружной рекламы, QR-кодов, афиш и соцсетей:
  - `/start ev_1` — моментально открывает интерактивную карточку конкретного события с бронированием, гео и кнопкой «Поделиться».
  - `/start promo_MAX2026` — активирует клубную скидку и копирует промокод в буфер обмена.

### 8. 📍 Геолокационный радар «Рядом со мной» (`request_geo_location`)
- Встроенный расчет расстояний по формуле **Haversine** с точностью до десятков метров.
- Фильтры по категориям (*Кафе, Выставки, Парки, Кино*) и вывод карточек с дистанцией (например, *«В 320 метрах от вас»*).
- Прямой переход к построению пешеходного или автомобильного маршрута на Яндекс.Картах (`link`).

### 9. ⚡️ Безопасное бронирование билетов (`request_contact` + HMAC-SHA256)
- Оформление электронного билета в 1 клик прямо в интерфейсе мессенджера.
- Защита от спама и перекупщиков: номер телефона верифицируется через защищенный контакт MAX (`vcf_info`).
- Криптографическая проверка подлинности контакта по алгоритму **HMAC-SHA256** с использованием токена бота.
- Генерация уникального билета `MAX-XXXX-XXXX` с сохранением в базу данных.

### 8. 🎫 Личный кабинет «Мои билеты» (`/my_tickets`)

### 13. 🚌 Городской Общественный Транспорт (`/transport`)
- База ключевых автобусов, троллейбусов, трамваев и катеров во всех городах РФ (автобусы №22, №94, катер «Графская — Северная» в Севастополе, метро Казани, автобус №м2 в Москве и др.).
- **Линии на карте.** В Mini App чип «🚌 Транспорт» слева на карте показывает остановки города; нажали на остановку, увидели проходящие маршруты и выбрали нужный. Маршрут рисуется линией с бегущими стрелками направления, остановками и движущимся значком, есть обратное направление. Данные: OpenStreetMap через Overpass (`/api/transit/stops`, `/api/transit/routes`, `/api/transit/route/{id}`), дисковый кэш в `data/transit`. Расписаний нет. Кэш наполняет `python scripts/build_transit.py [город ...]`.
- **Площадки города.** Театры и концертные залы, музеи и галереи, кинотеатры из OpenStreetMap: `/api/venues?city=` (адрес, сайт, телефон, часы), чипы «Театры» и «Музеи» на карте. Кэш в `data/venues`, наполняет `python scripts/build_venues.py [город ...]`.
- **Timepad (необязательно).** Если задан `TIMEPAD_TOKEN` (бесплатный токен на dev.timepad.ru), мероприятия Timepad попадают в афишу города наравне с Афишей и KASSIR.RU. Без токена источник не подключается.

### 13а. 🎨 Настоящие стикеры MAX (`/stickers_setup`)
Стикеры профиля отправляются в MAX как настоящие стикеры (вложение `sticker` с `code`), а не как картинка. API бота набор создать не умеет, поэтому набор делается один раз вручную:
1. В MAX откройте чат-бот «Стикеры в MAX», загрузите 8 файлов `webapp/assets/stickers/hermes-sticker-1…8.png` и сохраните набор.
2. Напишите своему боту `/stickers_setup <ADMIN_API_KEY>` (в демо-режиме ключ не нужен) и пришлите стикеры по порядку: бот запомнит их коды в `data/stickers/codes.json`.
3. Кнопки стикеров в профиле Mini App теперь шлют настоящие стикеры; пока кодов нет, отправляется картинка.

### 13б. 🏙️ Карточки городов и проверка перед показом
- Приветствие города в боте — та же фотография главной достопримечательности, что и в перелёте Mini App: название города, что на снимке, автор и лицензия. Готовые файлы лежат в `data/city_cards/` (56 городов, JPEG 1080×864). Пересобрать после замены фото в `webapp/assets/cities/` и манифесте `webapp/assets/city-photos.js`: `python scripts/build_city_cards.py [город ...]` (нужен только Pillow). Если файла нет, бот рисует запасную карточку сам.
- **Фото городов.** 56 снимков со свободными лицензиями Wikimedia Commons (`webapp/assets/cities/`, список авторов — `CREDITS.md` там же), у каждого лёгкий вариант `-m.webp` (800 px, ≈50 КБ) для телефона. Подпись «Фото: автор · лицензия» видна на главной, в перелёте, на `/stage` и на карточке бота.
- `python scripts/preshow_check.py` за минуту проверяет сервер, афишу по городам, транспорт, погоду, стикеры, бота в MAX, автозапуск, публичный адрес и сам Mini App в браузере. Шпаргалка для показа: `ПОКАЗ_ЖЮРИ.md`.

### 13в. 🎙 Рассказ о месте, прогулка с печатями и экран для сцены
- **Голос.** Гермес рассказывает только о конкретном месте и только достоверное: `/api/voice/story` берёт проверенную статью Википедии (с жёсткой проверкой, что она об этом самом месте) и пересказывает её по-человечески, `/api/voice/say` озвучивает текст живым голосом Gemini TTS (модели по очереди, у каждой своя квота), а когда квоты кончились, локальной нейросетью Piper (`ru_RU-ruslan-medium`, отдельный процесс `max_bot/services/voice_worker.py`: сбой нативной библиотеки не роняет сервер). Записи кэшируются в `data/voice`. Если достоверных сведений о месте нет, Гермес молчит; системного голоса браузера нет. Короткие фразы интерфейса («Гермес слушает», «Маршрут готов», «Вы на месте») с несколькими вариантами лежат в `PHRASES` и озвучиваются заранее (`python scripts/build_voice.py`). Кнопка «🔊 Послушать» есть на карточке события и в окне площадки, рассказ звучит на точках прогулки. `VOICE_ENGINE=piper` оставляет только локальный голос.
- **Прогулка.** В режиме «Узнать город» кнопка «Идти по GPS» включает стрелку-компас к следующей точке; на месте автоматически ставится печать Гермеса, звучит рассказ о месте, на карте тянется золотой след. «Демо-ходьба» проходит маршрут сама и ничего не засчитывает. Печати копятся в профиле и попадают на открытку маршрута.
- **Экран для сцены.** `/stage`: города один за другим — перелёт по карте-созвездию от прежнего города, «диафрагма» раскрывается в фото достопримечательности с медленным наездом камеры, титры, афиша, погода, пульс приложения и мини-карта со следом перелётов, без звука. `?autostart=1` запускает без кликов, `?city=Казань` — с нужного города, `?sec=8` — быстрый прогон (по умолчанию 15 с на город).

### 13г. 👥 Вечер вместе: друзья на карте и награда за приглашённых (`/party`)
Хозяин собирает вечер (можно с готовым маршрутом) и получает код и ссылку. Друг открывает ссылку, соглашается делиться геопозицией и появляется на карте у всех участников: метка с именем, расстояние, статусы «Иду», «Задержусь», «Жду». Хозяину +50 Coins за каждого нового друга, другу +25, обоим +30, когда оказались рядом по настоящей геопозиции. Бот: `/party` и кнопка «Вечер вместе» в меню. До регистрации Mini App в MAX бот ведёт в приложение (там человек гость-устройство); после неё он сам создаёт комнату, приглашение `?start=party_КОД` сразу делает человека участником и сообщает хозяину. Приватно: позиции видят только участники и только пока идёт вечер, их можно скрыть, а выход и завершение стирают координаты. Сервис `max_bot/services/party.py`, интерфейс `webapp/assets/party.js`, тесты `tests/test_party.py`. «Показать, как это выглядит» запускает демо без сервера и без начислений, он же шаг демо-тура.

### 13д. 🚋 Движение транспорта на карте (демо)
По выбранной линии едут несколько машин с направлением, нажатие показывает «следующая остановка, условно через N мин». Всё подписано «демо»: открытого источника настоящих позиций нет, при его появлении подставится он. Данные линий и остановок: OpenStreetMap.

| `callback` | Навигация по разделам, фильтры городов, шаги 3-клик ИИ-квиза, добавление в Избранное |
| `clipboard` | Копирование клубных промокодов (`MAX2026`, `ARTMAX`) и номеров электронных билетов в буфер |
| `request_contact` | Запрос верифицированного номера телефона покупателя билета для защиты от перекупщиков |
| `request_geo_location` | Отправка точных GPS-координат пользователя для работы гео-радара и автоопределения города |
| `message` | Быстрый шеринг события друзьям («📢 Поделиться событием в MAX») |
| `link` | Бесшовный переход к маршруту на Яндекс.Картах и открытие внешних порталов |

  отключение источников, ручное обновление города, модерация отзывов, журнал действий.
- **Песочница бота `/sandbox`**: тот же код бота в чате прямо в браузере, без токена MAX; есть личный чат и группа из трёх участников.
- **«Пойдём вместе» (`/together`)**: три варианта в групповом чате, голосование кнопками, итог со ссылкой.
- **Дайджест выходных (`/digest`)**: подписка, по субботам в 9:00 подборка событий города.
- **Персональные данные**: страница `/privacy`, выгрузка и удаление данных (`/privacy` в боте, кнопки на странице).
- **Рассылки организатора**: сообщение владельцам билетов на событие («начало перенесли»), с подсчётом получателей,
  подтверждением и историей доставки.
- **Импорт событий из CSV** с проверкой до записи и шаблоном; **резервные копии базы** раз в сутки (хранятся семь);
  **метрики** `/metrics` для Prometheus и **оповещения** на странице «Обзор» (устаревшая афиша, упавший источник, нет копии).
- **`/evening` — «Вечер за 1 тап»**: бюджет и настроение в два нажатия → событие вечера из живой афиши,
  маршрут пешком и кино одним сообщением.
- **Напоминания о билете**: за 2 часа бот присылает код, время и маршрут (раз на билет).
- **Отзывы после прохода**: оценить событие можно только по погашенному билету; в чате после гашения
  приходит приглашение со звёздами, в Mini App — звёзды в «Моих билетах».
- **Безопасность**: админка закрыта ключом, секрет webhook обязателен, `user_id` берётся из подписанной сессии MAX,
  проверка TLS включена по умолчанию (сертификаты Минцифры — в `certs/`), CORS сужен, коды билетов выпускаются
  криптостойким генератором, публичные тяжёлые запросы ограничены.

## 🚀 Инструкция по запуску

Для передачи проекта используйте `release/PulseGoroda-Portable-Windows.zip`.
Распакуйте архив и запустите `START_MINI_APP.bat`. EXE содержит Python runtime,
а свободный локальный порт выбирается автоматически. Подробная инструкция
подключения к MAX находится в `MAX_SETUP.md`.

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск в режиме консольного симулятора (без боевого токена!)
Позволяет протестировать абсолютно все сценарии прямо в красивом интерактивном терминале:
```bash
python main.py --mode simulator
```
*В симуляторе можно вводить команды (`/start`, `/city`, `/quiz`, `/random`, `/favorites`, `/search выставка`), нажимать кнопки по номерам `[1]`, `[2]`, отправлять координаты и симулировать передачу контакта с автоматическим расчетом валидного HMAC.*

### 3. Автоматический прогон всех 14 сценариев (Demo Runner)
Запуск автоматического сквозного тестирования полного пользовательского пути:
```bash
python scripts/demo_runner.py
```

### 4. Запуск FastAPI Webhook, Mini-App & Презентации
```bash
python main.py --mode webhook
```
- **Интерактивный Mini-App:** адрес из `startup.log` (для production нужен публичный HTTPS)
- **Track 3 Админ-панель & QR-сканер:** `/admin`
- **Интерактивная презентация:** `/deck`
- **Кинотеатры и сеансы REST API:** [http://localhost:8000/api/cinemas?city=Севастополь](http://localhost:8000/api/cinemas?city=Севастополь)
- **Фильмы и мультфильмы REST API:** [http://localhost:8000/api/movies](http://localhost:8000/api/movies)
- **Реестр городов REST API:** [http://localhost:8000/api/cities](http://localhost:8000/api/cities)
- **Каталог событий REST API:** [http://localhost:8000/api/events?city=Москва](http://localhost:8000/api/events?city=Москва)
- **Полнотекстовый поиск REST API:** [http://localhost:8000/api/search?q=выставка&city=Москва](http://localhost:8000/api/search?q=выставка&city=Москва)
- **Избранное пользователя REST API:** [http://localhost:8000/api/favorites?user_id=12345](http://localhost:8000/api/favorites?user_id=12345)

Укажите полученный токен бота в файле `.env` (`MAX_BOT_TOKEN=...`) и запустите:
```bash
python main.py --mode polling
```

## 🏆 Почему «Гермес» — победитель хакатона?

1. **Масштаб на ВСЮ Россию (56 городов)**: сервис не ограничен одним районом, а работает по всей стране с интеграцией геокодинга и маршрутизации **Яндекс.Карт**.
2. **SuperApp экосистема**: объединяет афишу событий, кино и мультфильмы по **Пушкинской карте (0 ₽)**, персональные ИИ-экскурсии, городской транспорт и кофейни.
3. **Реализация Track 3 «Арсенал мастера»**: встроенная админ-панель контролера и организатора (`/admin`) со сканированием и мгновенным гашением билетов.
4. **Полное задействование платформы MAX**: бот использует не только обычные текстовые сообщения, но и **все 5 типов кнопок**, защиту контактов через **HMAC-SHA256**, **Deep Linking**, а также **Mini-App**.
5. **Безупречная надежность**: полностью асинхронная архитектура, строгая типизация Pydantic v2, больше 430 автоматических тестов, чистый код без единого ворнинга.
6. **Гид по Казани**: встроенный гид по прогулкам и татарской кухне прямо в интерфейсе бота.
